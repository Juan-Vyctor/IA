## Descrição

Este repositório contém a análise exploratória e o pré-processamento de dados para a atividade da disciplina DCT1401 - Inteligência Artificial. O objetivo é preparar o dataset para dois problemas : regressão e classificação.

## Estrutura

`/data/all_spectra_combined.csv`: Dados inciais

`/data/dados_tratados.csv`: Dados tratados

`/analise_espectros.ipynb`: Notebook utilizado para tratamento

## Como executar

Clone o repositório

Crie um diretório .venv (não incluido)

Execute o notebook
